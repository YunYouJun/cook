# 菜谱搜罗

你在给 Cook（食用手册）按主题（某种食材、某种厨具、某个菜系）筛选并补充菜谱。补充数据时产出**一个** PR，由维护者审核合并。你从不直接推送到 main，也从不合并 PR。只询问标准或要求评审候选时，输出筛选结论和依据，不写数据或开 PR。

开始前读 [菜谱数据规范](../../docs/dev/data.md)，按其中「菜谱收录准则」筛选，按「数据规则」写入；不另设流量门槛或为凑数降低标准。

## 硬性规则

- 来源至少有 B 站视频（`bv`）或 HowToCook 图文（`link`）之一。小红书、下厨房等用于发现和交叉核对，不直接写入来源字段；图文导入遵守 `docs/decisions/0009-text-recipes.md`。
- **不编造来源或核验结果。** 搜索摘要和视频接口成功响应不足以证明教程可跟做；核对原文、字幕或可观察的操作。无法核实的列为暂缓，不写入 CSV。视频核验遵守数据规范的按需复核与冷却规则，不用直接请求绕过限制。
- 食材、厨具只能用 `packages/data/food.json` 里的名称。具体品种写成标准名（鲈鱼 → 鱼、虾仁 → 虾），对应别名加进 `packages/data/aliases.json`。
- `stuff` 和必要厨具须有教程内容依据；不能凭标题补猜，也不能漏掉尚未核实的必需主料后收录。`difficulty` 拿不准就留空。
- **id 不能修改、不能复用。** 新菜谱追加到末尾，id 用当前最大 id + 1。
- 按收录准则查重；同菜同做法优先补全已有条目，仅作者不同不新增。
- 需要新食材或新厨具时，写进 PR 描述的「需要维护者决定」，不要自己加进 `packages/data/food.json`（维护者明确要求的除外）。

## 步骤

1. **准备分支**

   先检查工作区和当前分支，保护未提交修改；需要隔离时用独立工作树。在合适的工作区从目标分支新建 `codex/recipe-sourcing-<主题>`，不重置已有分支。依赖缺失时再运行 `pnpm install --frozen-lockfile`。

2. **看现状**：在 `packages/data/recipe.csv` 里搜主题相关的菜，结合反馈和无结果组合看缺哪些常见做法、食材组合和厨具；按实际缺口找候选。

3. **找候选视频**
   - B 站搜索页（search.bilibili.com）和小红书一般禁止抓取，直接访问多半失败。可行的做法是用网页搜索，关键词带上 `bilibili.com/video` 和菜名，例如 `bilibili.com/video 红烧鱼 家常做法`、`bilibili.com/video 空气炸锅 秋刀鱼`，从结果里拿 BV 号。
   - 小红书能访问时，用来确认哪些菜做的人多，再去 B 站找对应视频。
   - 同一道菜先比较教学完整性和家庭可复现性，再参考作者、播放量和互动；不凭作者名直接通过。
   - 默认每个主题最多新增 20 道，没有最低数量要求；能找到几道合格菜就收几道，不循环追加核验批次凑数量。

4. **逐个筛选**：按收录准则给候选标记「收录 / 暂缓 / 不收录」，记录来源、作者、核验日期与方式、主料和必要厨具的内容依据，以及新增价值或未通过原因。缺少内容访问能力时保留候选，不把页面存在写成已验证可播放。

5. **写入数据**：只写通过筛选的菜，列为 `name,stuff,bv,difficulty,tags,methods,tools,id,link`，追加到 `packages/data/recipe.csv`，单元格内多个值用顿号「、」分隔。纯图文菜可留空 `bv`；新增 HowToCook 链接时按数据规范生成正文并核对导入差异。

6. **验证**

   ```bash
   pnpm validate --base origin/main
   pnpm fixtures
   pnpm test -- --run
   pnpm lint
   ```

   `test/recommendations.test.ts` 里的数量断言会随数据变化，只在变化是你新增的菜直接造成时才更新。`pnpm fixtures` 重新生成的 `packages/data/fixtures/*.json` 一起提交。

7. **提交并开 PR**：使用 Conventional Commits；PR 描述保留候选筛选证据，方便维护者抽查；说明哪些平台没能访问。没有数据改动就只报告筛选结果，不开 PR。

## PR 描述模板

```markdown
## 新增菜谱

| id  | 菜名 | BV / 图文路径 | 作者 / 项目 | 核验日期与方式 | 主料 / 厨具依据 | 新增价值 |
| --- | ---- | ------------- | ----------- | -------------- | --------------- | -------- |

## 暂缓 / 不收录

| 菜名 | 来源 | 结论 | 缺少的证据 / 原因 |
| ---- | ---- | ---- | ----------------- |

## 别名 / 词典

- ……

## 来源说明

- 能访问的平台、找不到视频的菜

## 需要维护者决定

- ……
```
