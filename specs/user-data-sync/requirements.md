# 收藏与浏览历史跨平台同步

- 日期：2026-11-06
- 关联：[#98](https://github.com/YunYouJun/cook/issues/98)
- 范围：现有 Web 与原生 iOS，收藏和浏览历史。

## 用户结果

用户在网页版收藏或浏览一道菜，主动启用同步后可以在 iOS 找回；断网期间仍能读写，恢复联网后合并修改。退出或切换云乐坊账号时，各账号记录相互隔离。

## 验收要求

- R1：当用户首次启用 iOS 跨平台同步时，系统应说明上传内容和数据归属；使用独立账号记录，不自动上传 Apple 账户中的旧记录。用户可以主动复制一次现有收藏和历史。
- R2：当同一账号在 Web 和 iOS 修改记录时，系统应按同一版本协议合并。收藏按菜谱 ID、操作时间取最新值；同刻删除优先。历史按菜名和浏览时间识别，保留最近 200 次；清空时间屏障与逐条删除均跨端生效。
- R3：当两个设备并发提交时，服务端应原子合并，不能用整份旧快照覆盖另一设备已接受的修改。
- R4：当请求中途退出、切换账号或关闭同步时，过期结果不得修改当前界面、缓存或另一账号数据；重试也应遵守当前会话。
- R5：当网络、认证、格式或写盘失败时，系统应保留已落盘记录，显示可理解的状态；离线修改在重启后保留，并在恢复联网或手动同步时重试。
- R6：当用户退出时，系统应停止请求并恢复本机/iCloud 记录；账号缓存继续保存在本机，重新登录同一账号才显示，不删除云端数据。
- R7：当远端版本未知或本地缓存损坏时，系统应停止覆盖写入并报告错误；客户端不能提交目标用户 ID，服务端只使用已认证身份。
- R8：当使用默认离线测试时，系统不应发起真实账号请求；线上验收应使用现有受管测试身份，并清理本轮会话和合成数据。

## 边界

维护者已于 2026-11-06 确认会员专享：Web 与 iOS 以及旧 get/set 均由服务端核验有效会员；过期后停止云端读写，保留本机记录与离线使用。

保留现有 SwiftData/CloudKit 和文件协议。冰箱、偏好、私人菜谱、媒体附件、Android、StoreKit 购买与正式发布不在本轮范围。
