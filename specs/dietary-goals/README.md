## 2026-10-27 实施收敛

维护者要求先在 iOS 端实现，交互采用原生系统组件。本轮提供系统列表选择目标、结果理由、已核对图文、随机候选联动和显式本机记忆；不增加 Web 界面或云端健康资料。

首批完成 32 道来源核对：“减少添加糖”12 道通过，“均衡搭配”32 道通过；“控制体重”只有 2 道具备本政策要求的份量与添加油证据，保持入口关闭。详见 [试标与首批核对记录](./audit.md)。

iOS 当前仅使用内置菜谱，没有可接入的在线菜谱更新器。本轮将可选标注与同一包内的图文、用量数据绑定，独立记录数据版本；原方案中的运行包生成、在线原子更新和跨端推荐一致性留到实际接入对应平台时完成。

## 问题与方向

2026-10-26 的应用内功能建议希望按控糖、减脂、生酮、备孕等饮食需求推荐菜谱，并用生活化问题引导选择。本计划仅保留匿名需求，不公开反馈人的联系方式、内部工单地址或其他个人信息。

Cook 已能回答“现有食材能做什么”，下一步是帮助用户找到符合自己饮食目标、且有具体依据的做法。入口名称为“饮食目标”，用户自主选择，默认不限，不要求登录或填写健康问卷。

## 首版决定

| 目标       | 首版交付                                                           | 明确的解释边界                                         |
| ---------- | ------------------------------------------------------------------ | ------------------------------------------------------ |
| 控制体重   | 份量、每份添加油用量参考，以及经过核对的做法                       | 表示便于核对份量和用油，不表示低热量、低脂或一定能减重 |
| 减少添加糖 | 推荐完整原料、调料和操作中已核对未额外添加糖的做法                 | 不等于总糖为零、低碳水、低 GI 或适合糖尿病管理         |
| 均衡搭配   | 标明菜谱提供的食物类别，并给出补充主食、蛋白质来源或蔬菜的搭配提示 | 单道菜不标为“营养全面”；首版不计算整餐营养达标情况     |

一次选择一个目标；目标内只展示该项审核通过且证据仍有效的菜谱。用户可以不选食材先浏览，也可以叠加现有食材、厨具、做法、难度与忌口。关闭目标后恢复原有推荐行为。

首批以现有图文菜谱为主，计划核对 30～50 道独立菜谱。公开上线时，已开放目标的有效通过记录合计至少覆盖 30 道独立菜谱、每个目标至少 10 道；同一道可以支持多个目标，总数按菜谱 ID 去重，不计入失败、未知或过期记录。数据不足时缩小开放目标或继续内测，不能用未审核菜谱补数。

生酮、备孕、孕期、痘痘相关饮食专题、疾病饮食、过敏原安全保证、每日能量处方及自动膳食计划进入后续评估，不作为首版交付承诺。

## 后续阶段

- V1.1：在首版使用反馈支持的前提下扩充菜谱，增加用户主动设置的多目标组合；组合关系和空结果解释另立验收。

## 事实基线与依据

在本代码基线下，`recipe.csv` 有 877 道菜，图文正文和用量标注各有 232 条，12 条用量标注包含显式 `referenceServings`。这些计数只说明现有数据覆盖率，不能代替逐条审核；没有该字段也不代表原文一定没有份数证据。

已存在的 `减脂餐`、`健康` 标签及原文预估卡路里不直接转为饮食审核结论。共享规则可复用现有食材匹配，但 `stuff` 只记录部分主料，不能承担完整调料审核或过敏原安全判断。

- [WHO：健康饮食](https://www.who.int/news-room/fact-sheets/detail/healthy-diet)：支持均衡、多样、适量的整体方向。
- [ADA：营养与饮食模式](https://professional.diabetes.org/clinical-support/nutrition-wellness)：血糖管理涉及碳水和份量等因素，不能等同于去掉添加糖。
- [AAD：饮食与痘痘](https://www.aad.org/public/diseases/acne/causes/diet)：部分研究支持低升糖饮食可能有帮助，证据仍有限，不据此建立“痘痘 → 消炎食谱”的自动规则。
- [CDC：备孕](https://www.cdc.gov/pregnancy/about/index.html)：孕前健康准备需单独考虑，不直接等同于孕期推荐。
- [既有 issue #84](https://github.com/YunYouJun/cook/issues/84)：相关背景是用户对饮食内容可靠性的质疑；其讨论内容不作为本功能的医学证据。

上述资料于 2026-10-26 核对，用于界定产品范围，不是单道菜营养认证或个性化饮食处方。
