# iOS 拿手菜徽章与模型展柜

后续待办与 Demo 截图见 [#239 拿手菜收藏](https://github.com/YunYouJun/cook/issues/239)。接续 [#235 做菜足迹](https://github.com/YunYouJun/cook/issues/235) 与 [MVP PR #238](https://github.com/YunYouJun/cook/pull/238)。

## 产品方向

用户主动确认「学会」后，获得对应菜肴的纪念徽章，并可在「我的拿手菜」中回看首次学会日期。后续增加可选的菜肴模型展柜，让拿手菜以小份料理的形态陈列、点选和旋转。

默认采用温暖克制的菜肴收藏，不加入每日任务、连续打卡、排行榜或等级压力。先验证徽章的收藏感，再决定模型资源的投入和覆盖范围。

## 已确定的数据边界

- 徽章与展柜由现有 `LearnedRecord` 派生，沿用官方／私人菜谱的稳定 `recipeID` 和 `learnedAt`，不增加第二份「已学会」真值。
- 浏览、完成计时或只记「做过」不解锁徽章，也不重复庆祝。
- 普通撤销学会后，徽章和展柜中的对应展示随之撤回，历史做过记录保留。
- 庆祝时即时撤销，沿用 `LearningConfirmation`，只回滚本次学会与本次自动补写的做过记录。
- 删除单次做过记录不收回学会徽章；删除私人菜谱后保留里程碑与安全占位。
- 展柜样式、摆放和视角属于展示偏好，不能修改做过或学会记录。继续保持本地存储边界。

## 第一阶段：菜肴徽章

从「我的 → 做菜足迹 → 我的拿手菜」进入徽章册，按首次学会时间倒序显示菜名、徽章和日期。每道已学会的菜显示一枚圆形纪念章，庆祝卡片同步预览这枚徽章。无障碍大字号改用单列，VoiceOver 将每枚徽章的菜名、日期和菜谱可用状态合为一项朗读。

番茄炒蛋、蒸蛋羹和拍黄瓜有独立插图，分别按官方菜谱 ID 250、588 和 497 关联。其他官方菜谱、私人菜谱及原菜谱不可用的记录使用通用餐盘。原菜谱不可用时，优先显示记录的菜名快照，并说明当前状态。

徽章册直接读取既有 `LearnedRecord`。只记做过时徽章册保持空白，删除做过记录后徽章仍可回看。普通撤销学会和庆祝中的即时撤销都会收回徽章。`CookingFootprintUITests` 覆盖这些状态，以及私人菜谱删除后和深色大字号下的显示。

## 第二阶段：可选模型展柜

番茄炒蛋（官方菜谱 `250`）是首个原生原型。在菜谱详情点「我做过这道」再确认「记为学会」，或在厨房工作台确认「今天学会了」。从「我的 → 做菜足迹 → 我的拿手菜」点按番茄炒蛋徽章，即可打开模型。左右拖动可连续转动，左右按钮每次转 30°，「复位」回到初始视角。

入口由现有 `LearnedRecord` 提供。只记做过时没有徽章和模型入口。删除单次做过记录后仍可打开模型，撤销学会则收回入口。蒸蛋羹、拍黄瓜和私人菜谱沿用静态徽章。

模型使用随 App 打包的 `TomatoEggAchievement.usdz`，约 1.4 MB。RealityKit 在打开时异步加载本地资源。旋转停稳后保留静态画面并释放实时场景；读取或快照失败时显示已有徽章与学会日期。系统启用减弱动态效果时，旋转按钮停用图标弹跳。旧真机性能和素材包安装留待后续验证。

模型与透明预览可在 Blender 4.4 中通过[场景脚本](../scripts/showcase/tomato_egg_clay.py)生成。命令的末尾参数指定独立输出目录，例如 `blender -b -P docs/scripts/showcase/tomato_egg_clay.py -- /tmp/cook-tomato-egg`。

- [ ] 先为少量代表菜制作模型，例如番茄炒蛋、蒸蛋、拍黄瓜；其余菜谱使用通用餐盘或徽章展示。
- [ ] 通过本地资源映射关联菜谱 ID 与模型，不改变菜谱 ID、历史记录或私人菜谱同步格式。
- [x] 用番茄炒蛋跑通徽章入口、拖动、按钮旋转和复位，静止时展示快照。
- [ ] 评估原生 RealityKit / USDZ 的包体、内存、首帧时间与旧机型表现，确认预算后再扩大资源覆盖。
- [ ] 模型缺失、损坏或设备不支持时降级为徽章，保留文字、日期与所有操作。
- [ ] 尊重 Reduce Motion、低电量与 VoiceOver；模型不是理解状态或完成操作的唯一途径。
- [ ] 私人菜谱默认使用本地通用模型；不自动向 AI 服务发送菜谱、照片或下厨记录。

## 本轮 Demo

会话中提供「徽章册／模型展柜」交互预览，使用固定示例记录与程序生成的简化菜肴模型，展示以下流程：

1. 选择尚未学会的番茄炒蛋，「只记为做过」只增加当天记录，不解锁徽章。
2. 主动点「今天学会了」，点亮徽章、显示庆祝，并按需补上当天做过。
3. 进入模型展柜，选择菜肴并旋转查看。
4. 体验庆祝即时撤销，以及「已学会」菜单里的普通撤销，比较做过次数的保留行为。

Demo 使用示例数据，不读取或写入 App 的真实本机记录。当前模型用于评估展示方向，不作为生产美术资源或原生性能验收依据。
