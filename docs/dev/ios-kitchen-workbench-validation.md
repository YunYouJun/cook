- 第一版完整 CookTests 62 项通过；增加半折布局后 66 项通过；增加展开竖屏边界后，6 项布局测试全部通过。

## 复现

生成共享数据和 Xcode 工程后，运行 Cook scheme 的 `CookTests` 与 `CookUITests/KitchenWorkbenchUITests`。CI 沿用 iPhone / iPad 双设备检查。

模拟器启动超时时，先运行 `python3 apps/ios/scripts/prepare-simulator.py <UDID>`，再对同一设备执行测试。脚本等待完整启动，不清空设备或重启全局模拟器服务。

Duo 姿态需要 iOS 27.1 运行时。在 Device Hub 中从外屏打开工作台，勾选一项并暂停计时，再逐一展开、半折、旋转和闭合，核验布局与状态保持。完整本地 JSON 结果、启动日志和截图保留在任务工作区；仓库保留本记录。
