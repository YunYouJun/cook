# 我的拿手菜 · 离线素材

在「我的 → 做菜足迹 → 我的拿手菜」打开已学会的番茄炒蛋、蒸蛋羹或拍黄瓜。徽章和首次学会日期来自本机学会记录。每道菜的图片包和模型包单独显示大小、下载进度和删除入口。下载模型后点「查看 3D」可手动旋转、分步转动和复位，停在一个角度时由静止快照接管。两份素材都可在断网时从本机打开。删除图片包后成就页显示徽章，删除模型包后仍可看已下载的图片。每道菜有自己的安装目录，删除素材不改变学会日期和做过记录。

## 发布与更新

- 每道菜的素材在 `assets/showcase/<配对 ID>/`，统一为 `image.webp` 和 `model.usdz`。番茄炒蛋（250）沿用先前验收的软陶模型和配图。蒸蛋羹（588）和拍黄瓜（497）将 #239 的 Demo 造型转成同风格的原生资源，共用米白釉面、薄荷绿盘沿和相机。
- [番茄炒蛋生成脚本](../scripts/showcase/tomato_egg_clay.py)和[蒸蛋羹及拍黄瓜导出脚本](../scripts/showcase/export_demo_dishes.py)从各自场景输出透明预览与 USDZ。后一个脚本可用 `blender -b -t 4 -P docs/scripts/showcase/export_demo_dishes.py -- <独立输出目录>` 重跑，再用 `cwebp -q 88 -m 6` 把 768 像素的 PNG 转成透明 WebP。
- App 安装包只带徽章和 `showcase-packs.json` 清单。清单按菜谱 ID 和配对 ID 关联两份素材，按包固定版本、URL、字节数和 SHA-256。更新其中一份素材时递增对应包的版本，写入新的大小和哈希。路径中包含版本和哈希，旧版持有的 URL 继续可用。
- `Showcase Assets` 工作流使用仓库现有 COS 上传凭据，发布到 `cook/showcase/<菜谱 ID>/<配对 ID>/`。发布前检查清单与原文件，上传时避免覆盖旧对象。首发和升级都应先从 EdgeOne 下载新素材、复核大小和哈希，再分发引用它的 App 构建。
- iOS 将通过校验的文件原子写入 `Application Support/CookShowcaseAssets`，并把目录排除在设备备份之外。更新取消或校验失败时可以继续使用以前的版本。仅在完成安装后移除旧版本。删除包只清理对应菜品和类别的本机版本。番茄炒蛋继续使用原本的目录，已下载素材可继续使用。
