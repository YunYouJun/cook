# 我的拿手菜 · 离线素材

在「我的 → 做菜足迹 → 我的拿手菜」打开番茄炒蛋的成就。徽章和首次学会日期来自本机学会记录。图片包约 30 KB，模型包约 1.39 MB，各自显示大小、下载进度、使用状态和删除入口。下载模型后点「查看 3D」可旋转和复位。两份素材都可在断网时从本机打开。删除图片包后成就页显示徽章，删除模型包后仍可看已下载的图片。删除素材不改变学会日期和做过记录。

## 发布与更新

- 首组配对用公共菜谱 ID `250` 和 `tomato-egg-clay`。仓库 `assets/showcase/tomato-egg-clay/` 保存同一场景渲染的透明 WebP 和 RealityKit 用 USDZ，生成脚本在 `docs/scripts/showcase/tomato_egg_clay.py`。配图缩到 768 像素宽，模型沿用已验收的 USDZ 文件。
- App 安装包只带徽章和 `tomato-egg-clay.json` 清单。清单按包固定版本、URL、字节数和 SHA-256。更新其中一份素材时递增对应包的版本，写入新的字节数和哈希。路径中包含版本和哈希，旧版持有的 URL 继续可用。
- `Showcase Assets` 工作流使用仓库现有 COS 上传凭据，发布到 `cook/showcase/250/tomato-egg-clay/`。发布前检查清单与原文件，上传时避免覆盖旧对象。首发和升级都应先从 EdgeOne 下载新素材、复核大小和哈希，再分发引用它的 App 构建。
- iOS 将通过校验的文件原子写入 `Application Support/CookShowcaseAssets`，并把目录排除在设备备份之外。更新取消或校验失败时可以继续使用以前的版本。仅在完成安装后移除旧版本；删除包会清理这一类素材的所有本机版本。
