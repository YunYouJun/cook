## 反馈 SDK 部署修复

生产 `cook-feedback` 的源码与当前源码一致，但安装的 Support SDK 仍为 0.2.0，会丢弃回执中的可选私密工单链接。真实提交已收到成功回执，应用因此没有显示回访入口。当前 iOS 已支持该入口，无须修改或重打候选 IPA。

使用现有 `scripts/prepare-support-feedback.mjs` 和校验过 SHA-256 的私有发布包，已准备 SDK 0.3.0 函数包与原生产回滚包。全依赖比较只有该 SDK 的版本变化；SDK 链接校验 6 项、反馈适配器 31 项测试全部通过。

维护者确认后，仅更新生产 `cook-feedback` 的代码。MCP 首次更新因 `ResourceNotFound.Package` 未成功，原代码仍可用；改用项目现有 CLI 完成相同代码包更新。函数回读为 `Active`，运行时、环境变量、权限相关配置和触发器等 17 项配置均一致；下载线上代码包确认 SDK 为 0.3.0，函数源码不变。使用同一 Release 7 再次提交合成反馈后，私密查看入口出现；实际点击后进入工单页，显示本次合成反馈，`feedback_privacy` 已补齐。没有发送真实用户回复或通知。
