# 云食册 iOS 内测

有什么食材，就做什么菜。云食册是「食用手册」的原生 iPhone / iPad 应用：选食材和厨具找菜、查看做法、收藏菜谱，也可以记录冰箱和自己的菜谱。

::: info 开放状态
外部测试准备中，尚未开放公开加入。收到开发者的 TestFlight 邀请后再安装；本页会在开放时更新加入入口。准备中的构建不代表已通过 Apple 的外测审核。
:::

## 怎么安装

1. 准备 iOS 17 / iPadOS 17 或更新版本的 iPhone / iPad，从 App Store 安装 [TestFlight](https://apps.apple.com/app/testflight/id899247664)。
2. 收到邀请后，在设备上打开邀请，进入 TestFlight，核对应用名称「云食册 - 食用手册」并安装。
3. 已安装云食册的用户直接更新；更新前可在 App 内导出收藏、历史、私人菜谱及个人食材/厨具配置。请保留重要数据的备份。

核心功能不需要注册账号。选食材、搜索、推荐和已内置的文字做法可以离线使用；配图、在线视频与发送反馈需要网络。测试版本有使用期限，以 TestFlight 显示为准。

## 这次想请你试什么

不用一次做完，先用家里现有的食材找一顿想做的饭。

| 场景                           | 请留意                                             |
| ------------------------------ | -------------------------------------------------- |
| 选食材、厨具或输入一句话找菜   | 找到想用的食材是否方便，推荐能否帮你决定做什么     |
| 打开做法、收藏、再次查找       | 图文是否好读，来源链接能否打开，重启后收藏是否保留 |
| 记录冰箱食材和到期日           | 添加、修改和移出是否顺手，拒绝通知后能否正常使用   |
| 创建自己的菜谱                 | 新建、编辑、删除和文件备份是否符合预期             |
| 管理食材和厨具                 | 添加、隐藏和恢复条目后，选择器是否正确变化         |
| 调整字体、深色模式或 iPad 分屏 | 是否有遮挡、文字截断、按钮难以点击                 |

## 当前范围与已知限制

- iCloud 同步仍待真实生产环境和双设备验收，目前不作为已验证能力对外承诺。个人食材/厨具配置和临期提醒设置只保存在当前设备。
- iOS 和 Web 之间通过文件手动迁移，尚未提供账号自动同步。收藏/历史、私人菜谱、个人配置分别使用各自的备份文件。
- iOS「我的菜谱」支持保存、编辑和查看，暂不参与内置菜谱推荐、收藏和浏览历史；私人菜谱不会自动公开。
- 来源视频使用外部 App 或浏览器打开。私人菜谱文件不包含图片或视频附件。

## 怎么反馈

优先使用 **云食册 → 我的 → 意见反馈**，或者通过 TestFlight 发送反馈。应用内提交的意见进入团队的私密处理队列，不会自动发布到需求墙。

反馈时请附上：应用版本和构建号、设备及系统版本、操作步骤、预期与实际结果；截图中的个人信息请先遮挡。数据保存或同步异常请尽量提供发生时间，并保留备份。

也可以访问 [云乐坊支持中心](https://support.yunle.fun/?product=cook)。适合公开讨论的功能建议可提交到 [需求墙](https://support.yunle.fun/feedback?product=cook)，不要在那里发布私人菜谱、联系方式或账号信息。

## 隐私与你的选择

推荐统计默认关闭，拒绝不影响功能；通知也需要你主动开启。完整内容见 [云食册隐私政策](/privacy)，App 内也可以离线阅读。

隐私问题和数据删除请求请使用隐私政策中的联系方式。测试反馈不需要提供 Apple 账号密码或完整的数据备份。
