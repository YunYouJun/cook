# 0018 冰箱拍照录入与食用时间建议

- 状态：已实施，待随版本分发
- 日期：2026-11-10

## 背景

冰箱已有手动添加、通用冷藏天数和本地提醒。拍摄包装可减少输入，蔬果则需要按种类给出食用计划，并区分真实包装日期与建议日期。

## 决定

- iOS 冰箱增加拍照与系统照片选择器。Apple Vision 在本机识别文字与常见蔬果具体类别；不用云端多模态模型，不依赖账号、会员或个人 Key。照片只在内存处理，按方向缩至最长边 2400 像素；不保存照片和 OCR 原文。
- 一次核对一份食材。食材、日期与依据须在确认页核对后保存，多个候选名称由用户选择。通用 `fruit` / `vegetable` 类别、低置信度结果不会自动猜成具体蔬果。
- 包装上明确标注的到期日优先；缺少到期日时，识别完整生产日期和唯一保质期后按自然日／公历月／年推算。推算提示核对包装的起算方式和储存条件。无标签日期、日期冲突、非法日期、未来生产日期不自动补为确定到期日；识别出的有效日期可手动点选。
- 蔬果按种类给出完整冷藏建议，切开或去皮时从切开日期起算。用户可修改购买／切开日期、建议日期和日期依据。已有日期不会因为更改食材而被建议静默覆盖。
- 拍照入口提供蓝莓、西瓜的可展开记录示例，确认相应食材后在食用建议旁展开说明。蓝莓按实际购买日期和完整冷藏条件安排；完整西瓜按成熟度手动设定计划，切开后再按实际切开日期与冷藏条件采用建议。示例不会创建冰箱记录或自动开启提醒；切开也不会延长该种类原有的建议天数。
- 日期依据保存为食用建议、包装标注、生产日期与保质期推算或自设食用计划。列表和通知分别显示“建议明天吃完”和“明天到期”，不以“还新鲜”承诺食用安全。
- 继续使用既有本地通知：用户主动开启权限，在记录日期前一天和当天提醒，同日汇总。新增、修改、删除、同步和依据变化均重排。通知的实际显示仍受系统权限和通知设置影响。

## 建议依据

- [University of Maine Cooperative Extension 储存表](https://extension.umaine.edu/food-health/2025/05/29/storing-and-washing-fresh-fruits-and-vegetables/)：完整冷藏蔬果按公开区间较短端安排，切开蔬果默认 3 天，切开番茄 2 天，冷藏条件为 4℃ 或以下。建议用于安排食用，不是保证安全的期限。
- [FDA FoodKeeper 说明](https://www.fda.gov/food/consumers/how-cut-food-waste-and-maintain-food-safety)：完整苹果冷藏区间取较短端 28 天。
- 未覆盖种类继续显示既有 `shelf-life.json` 通用天数，并明确缺少专属建议。照片不能识别购买前的储存历史、内部污染或保证食物安全。
- 技术使用 [Apple Vision 文字识别](https://developer.apple.com/documentation/vision/recognizing-text-in-images) 和 [图像分类](https://developer.apple.com/documentation/vision/vnclassifyimagerequest)。

## 数据与发布

`FridgeItem` 新增可选的 `productionDate`、`expiryBasisRaw` 和 `storageAdvice`，旧记录默认按估算解释。日期沿用 UTC 年月日存储，显示时转换到本地同一自然日。CloudKit schema 升到 4；分发前需部署新增字段到 Production，并核验真实同步。相机使用说明由 `project.yml` 生成，隐私说明随 App 打包更新。

模拟器可验证 OCR、日期解析、确认保存与本地排程；真实相机权限与拍摄、不同包装反光／喷码／模糊情况、蔬果实拍准确率和新字段生产同步需另行验证。

## 本轮验证

- iPhone 18 Pro / iOS 27.0：42 项冰箱、持久化、迁移和通知路由单元检查，以及 4 项界面流程通过；补充中文包装图后，14 项录入检查再次全部通过。中英文 OCR 均由程序生成的标签图片实际调用 Vision 验证，不代替实拍准确率评估。
- iPad Pro 13-inch (M5) / iPadOS 27.0：取消拍照后手动添加水果、包装识别确认保存并移出、无包装日期的蔬果建议，3 项原始界面流程通过。首次因仓库已记录的中文输入法等待问题中断；同一设备切为 English (US) 后复用构建重跑，保留原断言，没有新建或清空设备。
- 最终 iOS 模拟器编译、修改文档的 ESLint 和 `git diff --check` 通过。本轮没有上传 TestFlight 或部署 CloudKit schema。
- 补充蓝莓与西瓜引导后，14 项录入检查及 1 项示例阅读流程通过；展开两组说明、滚动阅读并取消后，冰箱保持为空。
