# 0014：个人食材和厨具

状态：已实施，基于 #124，回应 #18、#77。

个人食材和厨具独立于公共词典。内置条目可隐藏、恢复，自定义条目可添加、删除；这些操作只影响选择器，不改写已有菜谱、冰箱记录和忌口。已选项保持可见并可取消，避免隐藏筛选条件。重复名称按食材或厨具去重，食材别名仍沿用公共标准名。

配置保存在设备本地，Web 使用 localStorage，iOS 使用原子写入的 JSON 文件。使用独立的 `cook/personal-catalog` v1 JSON 文件迁移，两端格式一致。导入先预览并确认，合并新增条目和隐藏偏好，不替换既有类别。整个文件验证通过并成功保存后才更新界面；读取或保存失败不覆盖原文件。

菜谱视频只记录在线链接或 BV 号，点击菜名直接打开来源；备注和编辑保留独立详情入口。不导入、存储或内嵌播放视频文件，菜谱 JSON 继续仅包含文字和链接。本轮不改变 #124 的生产 schema 或验收范围。

不在本轮增加账号服务、公共投稿或 native 私人菜谱的整数 ID；后者在加入收藏、历史及推荐前仍需设计统一身份。
