# 方案记录

记录项目里做过的重要决定：当时的问题、考虑过的方案、选了什么、为什么。之后想改方向时，先看这里，避免重复讨论。

## 怎么写

- 每个决定一个文件：`docs/decisions/NNNN-简短英文名.md`，编号递增。
- 状态：提议中 / 已采纳 / 已废弃 / 被 NNNN 取代。改变决定时新写一篇并更新旧篇状态，不要直接改写旧结论。
- 结构：背景、方案对比、决定、影响，写清楚取舍即可，不用长。
